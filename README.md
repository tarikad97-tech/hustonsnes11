# Houston Local Guide (houstons.com)
Static site generated by a dependency-free Node script (Node 18+).

**Before launch:** check trademark risk for the "Houston's" name; the brand lives in `config/site.json` (`name`) and can be changed there.

## Run
`node build.mjs` builds to `dist/`. Preview: `npx serve dist` (or `python3 -m http.server -d dist`).

## Add an article
1. Write the body (H2/H3 HTML only, no H1) in `content/<slug>.html`.
2. Add an entry to `data/articles.json`: `slug, title, description, category, date, updated?, author, image?, imageAlt, imageWidth, imageHeight, keywords[], sources[{label,url}], published:true`.
3. Only verified facts, with official sources. Run the build.

## Add a category
Add `{slug,title,intro}` to `categories` in `config/site.json`.

## Settings
`config/site.json`: name, url, contact, editor, `analyticsId`, `adsensePublisherId`. Empty values are never rendered as fake IDs.

## Deploy (Cloudflare Pages)
Push to GitHub → Cloudflare Pages → Connect repo. Build command: `node build.mjs`; output directory: `dist`. Then Custom domains → add houstons.com and confirm DNS/HTTPS status in the dashboard.

## Search Console / Analytics / AdSense
- Search Console: add a Domain property, verify via DNS TXT, submit `https://houstons.com/sitemap.xml`.
- Analytics: set `analyticsId`, update `/privacy-policy/` first, and add consent if required.
- AdSense: apply only once there is enough original content; set `adsensePublisherId` to generate `ads.txt`; add ad code in the layout only after approval.
